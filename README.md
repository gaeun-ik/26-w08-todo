# 🌷 오늘의 작은 목록

하루의 할 일을 기록하고 하나씩 완료해 나가는 반응형 To-Do 리스트입니다. 할 일과 중요도, 선택 마감일을 입력하고 진행률을 확인할 수 있습니다.

## 주요 기능

- 할 일 추가 및 삭제, 완료/미완료 전환
- 중요도(높음·보통·낮음)별 배지 표시
- 선택 마감일 입력 및 목록 표시
- 전체·진행 중·완료 필터
- 완료 개수와 진행률 바 실시간 표시
- 빈 목록 및 필터 결과가 없을 때 안내 표시
- 브라우저 `localStorage`에 저장해 새로고침 후에도 유지
- 입력한 HTML을 실행하지 않고 일반 텍스트로 표시
- 할 일을 완료할 때 꽃잎 효과 표시

## 어떻게 만들었나요

먼저 [PRD.md](./PRD.md)에 기능과 완료 기준을 정리하고, 그 기준을 반영한 구현 계획을 세운 뒤 Vanilla JavaScript와 Tailwind CSS CDN으로 구현했습니다. 이후 마감일 입력을 간단한 날짜 선택기로 다듬고, 완료 시 꽃잎 효과를 추가했습니다.

## Bootstrap vs Tailwind

현재 작업 버전은 Tailwind CSS를 사용합니다. Tailwind는 간격·색상·레이아웃 등의 유틸리티 클래스를 HTML에 조합해 화면을 구성하고, Bootstrap은 미리 정의된 컴포넌트와 유틸리티를 활용합니다. 이 구현에서는 원하는 카드형 레이아웃과 반응형 스타일을 클래스 단위로 빠르게 조정할 수 있어 Tailwind 버전을 사용했습니다.

이 작업에서는 Bootstrap 버전과 실제 화면을 나란히 실행해 비교하지 않았으므로, 두 버전의 시각적 차이에 대한 비교 결과는 포함하지 않았습니다. 실습 과정은 [guide.md](./guide.md)를 참고하세요.

## 실행 방법

빌드 도구나 패키지 설치 없이 실행할 수 있습니다. 저장소 루트에서 간단한 로컬 서버를 시작하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 열어 확인합니다. Tailwind CSS를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

GitHub Pages를 설정하면 [https://gaeun-ik.github.io/26-w08-todo/](https://gaeun-ik.github.io/26-w08-todo/)에서 사용할 수 있습니다.

## 커스터마이징한 부분

- 마감일을 년·월·일 각각 입력하는 대신 날짜 선택 칸 하나로 구성했습니다. 날짜는 할 일과 함께 저장되며 목록에도 표시됩니다.
- 완료 체크 시 체크박스 주변으로 꽃잎이 퍼지는 효과를 추가했습니다. 기기에서 동작 줄이기를 설정한 경우에는 애니메이션을 생략합니다.
- 긴 할 일은 최대 50자로 제한하고, 공백만 입력한 경우에는 추가하지 않습니다.
- 모바일 화면에서도 입력과 목록을 사용할 수 있도록 반응형 레이아웃을 적용했습니다.
